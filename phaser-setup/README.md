# Phaser Game Setup

## Project Overview
This project is a basic setup for a Phaser game. It includes the necessary files to get started with game development using the Phaser framework. 

## Purpose
The purpose of this project is to provide a simple structure for beginners to learn and experiment with Phaser game development.

## Project Structure
The project consists of the following files:
- `index.html`: The main HTML document that loads the Phaser game.
- `main.js`: The JavaScript file containing the game logic.
- `directions.md`: Instructions for setting up the project.
- `README.md`: General information about the project.

## Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, etc.)
- A code editor (e.g., VS Code, Sublime Text)

### Installation
1. Clone the repository or download the project files.
2. Open the project folder in your code editor.

### Running the Game
1. Open `index.html` in your web browser.
2. You should see the Phaser game running.
